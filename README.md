📊 Marks and Grade Analyzer


## About the Project
Marks and Grade Analyzer is a beginner-friendly Python project that calculates students' marks, percentage, grades, and final results. It also allows users to store multiple student results temporarily and search for a student's result by name.

## Features
- Add student results
- Enter multiple subjects and marks
- Calculate total marks and percentage
- Find highest and lowest marks
- Automatically calculate grades (A+, A, B, C, D, F)
- Display Pass or Fail result
- Search student results by name
- Case-insensitive student search
- Menu-driven program

## Concepts Used
- Python Variables
- Lists
- Dictionaries
- While Loop
- For Loop
- Conditional Statements
- User Input
- Built-in Functions (`sum()`, `max()`, `min()`)
- String Methods (`lower()`)

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code or any Python editor.
3. Run the Python file.
4. Select an option from the menu.

## Example Menu
1. Add Student Result
2. Search Student
